Built for two computers on one desk.

The host is the computer with the mouse and keyboard plugged in. Clients are the ones it controls. Every feature can be switched off, everywhere or for one device.

Arrange screens like your desk

Drag the laptop next to the monitor it sits beside. The cursor crosses only where the edges touch, so moving between your own monitors stays a normal Windows move. A laptop at 150% scaling sits next to 100% monitors at its real size.

Drop a file to send it

Files stream over the encrypted connection, are checked with BLAKE2s when they arrive, pick up where they left off after a dropped connection, and wait for approval on the other side. Text and links go across in one click.

No stuck keys

Every key is released on the computer that got the press, even when the connection drops or the session locks.

Per-device permissions

Allow clipboard, files and text for each paired computer separately.

Lives in the tray

Close the window and Moush keeps working in the notification area, using about 16 MB of memory.

At home on Windows 11

Light, dark and high contrast themes, Mica, and fewer animations when Windows asks for them.

Your input stays between your computers.

There is no account and no cloud service. Your computers connect to each other directly on your network, and every connection is encrypted and authenticated.

  • Pair with a code. A new computer has to be allowed on both sides, after you check that the same 6-digit code shows on each screen.
  • Encrypted on every connection. Noise XX with X25519, ChaCha20-Poly1305 and BLAKE2s. Paired computers prove who they are each time they reconnect.
  • You decide what crosses. Clipboard, files and text can each be turned off, everywhere or per device.

Set up in a couple of minutes.

Install Moush on each computer. Both need to be on the same network.

  1. Install on both computers

    Run the installer on each. It installs for your user only and needs no admin rights.

  2. Choose Host and Client

    Host on the computer with the mouse and keyboard, Client on the other. When Windows asks, allow Moush on private networks.

  3. Pair them

    On the client, select the host under Devices. Check that the 6-digit codes match, then select Allow on both.

  4. Arrange your screens

    On the host, open Devices, then Screen layout. Drag the laptop to where it sits on your desk and save.

Questions

Do I need an internet connection or an account?

No. Your computers talk to each other directly over your local network, and there is nothing to sign in to.

Does it work over Wi-Fi?

Yes, as long as both computers are on the same network. Guest Wi-Fi networks usually keep devices apart, so use your main network. If the host doesn't show up, type the IP address from the host's Diagnostics page.

How much delay does Moush add?

About 50 microseconds of processing, on top of the time your network takes to carry the input. Diagnostics has a latency test that measures your own connection.

Can it control the lock screen, Ctrl+Alt+Del or UAC prompts?

No. Windows keeps those screens private, so no app can send input to them. When the host locks, the cursor comes back to the host automatically.

What about apps running as administrator?

Windows blocks input from normal apps into elevated windows. To control them on a client, run Moush as administrator on that client.

How do I get the cursor back quickly?

Press Ctrl Alt Esc, or choose Bring cursor back to this computer from the tray icon. Press Scroll Lock to keep the cursor on the computer it is on.

Does it run on macOS or Linux?

Not today. Moush is built on Windows input APIs and runs on Windows 10 and 11.
